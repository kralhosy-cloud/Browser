# Erişilebilirlik

- Klavye: Tab/Shift-Tab ile sekme çubuğu → adres → kalkan → içerik sırası; odak halkası görünür (Fluent tema).
- Screen reader: `AutomationProperties.Name` her düğmede Türkçe (Geri, İleri, Yenile, Ana menü).
- High contrast, zoom 100–200%, `prefers-reduced-motion`.
- Güvenlik uyarıları yalnızca renk değil: ikon + metin (🔒 güvenli, ⚠️ sertifika hatası).
- URL/title remote control karakterleri ile taklit edilemez — screen reader’a verilen metin NUL/control strip’li.
- Türkçe arayüz eksiksiz; çeviri altyapısı `I18N/*.resx`.
